OrbDeck Website
===============

Das ist eine normale statische Website ohne Framework und ohne Build-System.

Dateien:
- index.html
- style.css
- script.js
- assets/orbdeck-icon.svg
- assets/og.png

Lokal testen:
1. Das ZIP vollständig entpacken.
2. index.html doppelklicken.

Hochladen:
Alle Dateien und Ordner gemeinsam in das gewünschte Web-Verzeichnis kopieren.
Die index.html muss neben style.css, script.js und dem assets-Ordner liegen.

Es werden weder Node.js noch eine Datenbank oder serverseitige Funktionen
benötigt.

Die neueste Version, der Downloadlink, die Dateigröße und die Prüfsumme
werden direkt aus den öffentlichen Releases von
https://github.com/Nexiii/OrbDeck geladen. Ist GitHub vorübergehend nicht
erreichbar, bleibt der mitgelieferte Release als sichere Rückfallebene
sichtbar.
